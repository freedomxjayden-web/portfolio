喵哨站

部署防線，守住最後補給站。

以貓咪同最後補給站做主題，將部署、資源分配同生存挑戰放入一個瀏覽器塔防遊戲。

開始遊戲 ↗ （於新分頁開啟）

版本與驗證

喵哨站 1.4.0 · 首局教學、暫停管理與離線版

核對日期 2026-10-31 · 已核對本機版本、公開入口及文件；驗收範圍與限制見下文。

可以做咩？

  • 選炮塔、揀空格部署，守住基地四周。
  • 點選炮塔升級或換裝，喺戰況變化時調整防線。
  • 支援暫停、震盪脈衝，同手機點格後確認部署。

點樣開始？

  1. 打開遊戲，按畫面提示開始。
  2. 選炮塔，再揀空格部署；手機需要確認部署。
  3. 選中炮塔升級或換裝，隨戰況調整防線。
實作、來源與限制 +

點樣實作？

遊戲喺瀏覽器本機運行。公開部署包含 HTML 入口、JavaScript 同 CSS 資源，透過 GitHub Pages 發布。

最高生存紀錄同音效設定保存在瀏覽器本機，毋須登入。介面提供選塔、部署、升級同換裝嘅操作流程。

可略過嘅首局教學帶你部署、升級同使用脈衝；管理、手動、教學及分頁暫停分開處理。

驗證與限制

1.4.0 於 2026-10-31 通過 45 項規則及教學測試；正式網站已核對成功部署推進教學、管理入口及下載版離線遊玩。實體手機及真人試用未完成。

公開儲存庫主要存放正式部署檔案，未公開嘅原始架構、演算法同開發流程不作推測。

本機紀錄依賴瀏覽器儲存；清除網站資料或轉用其他裝置，紀錄唔會自動同步。
