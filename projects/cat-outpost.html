喵哨站

可以做咩？

  • 選炮塔、揀空格部署，守住基地四周。
  • 點選炮塔升級或換裝，喺戰況變化時調整防線。
  • 支援暫停、震盪脈衝，同手機點格後確認部署。

點樣開始？

  1. 打開遊戲，按畫面提示開始。
  2. 選炮塔，再揀空格部署；手機需要確認部署。
  3. 選中炮塔升級或換裝，隨戰況調整防線。
實作、來源與限制 +

點樣實作？

遊戲喺瀏覽器本機運行。公開部署包含 HTML 入口、JavaScript 同 CSS 資源，透過 GitHub Pages 發布。

最高生存紀錄同音效設定保存在瀏覽器本機，毋須登入。介面提供選塔、部署、升級同換裝嘅操作流程。
