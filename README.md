# x Portfolio / 個人作品集

https://freedomxjayden-web.github.io/portfolio/

A static portfolio in Hong Kong Traditional Chinese and English. It includes three projects, real screenshots, standalone design and implementation cases, technologies used, a development journal, project philosophy and contact links.

## Structure

- `index.html` — portfolio homepage.
- `projects/` — Cloud Drive, Cat Outpost and Stock Atlas case studies.
- `content.js` — bilingual content and per-page metadata.
- `script.js` — language preference, accessible navigation and image previews.
- `styles.css` and `assets/` — shared design and real screenshots.

No installation, build step or backend is required. To preview locally, run `python3 -m http.server 4173` in this directory. GitHub Pages publishes the main branch from the repository root.

Update the HTML default content and both language dictionaries together. Status labels and journal entries are maintained manually. Screenshots and historical verification records do not indicate live service availability. Project sites are maintained separately.
